# 🦀 TV Pilot — Workspace Rules (AGENTS.md)

Компактный корневой свод правил для работы любой ИИ-модели (оптимизировано под контекст **Flash** через Progressive Disclosure).

## 1. Суть проекта и продуктовая философия
- **Путь:** `E:\Project\TV Pilot`
- **Стек:** Rust (`edition = "2024"`, Cargo Workspace: `crates/tv-pilot-core` + `crates/tv-pilot-cli`).
- **Назначение:** Управление, запуск фильмов без лагов и внешняя защита телевизоров Android TV / Google TV (тестовый стенд: `172.30.0.176`, TCL `R51MT05`, Realtek `RTD2851M`, 2 ГБ RAM).
- **Кроссплатформенность:** Ядро `tv-pilot-core` пишется на чистом асинхронном Rust (`tokio`, `reqwest`, `serde`, `thiserror`) для работы на ПК (сейчас), macOS и Android (в будущем).
- **💎 Философия «Честный софт для обычных людей» (Zero-Data, No JWT/Tokens, Instant Wow):**
  - **Никаких токенов, JWT, OAuth и облачных привязок:** в проекте категорически запрещены любые авторизации, токены, сбор аналитики и внешние соединения. Пользователь купил телевизор — он должен работать быстро и локально без «шулерства» корпораций.
  - **Для людей, которые не разбираются в технологиях:** человек не обязан знать, что такое битрейт, `zram`, `ADB`, `eMMC` или `Remux`. Для него всё работает в одну кнопку на понятном человеческом языке: авто-поиск ТВ в домашнем Wi-Fi -> наглядное ускорение («Было / Стало») -> фильм включается без лагов -> телевизор защищён снаружи с 0 МБ нагрузки на память.

## 2. Жёсткие инварианты («Никуда больше не лезем»)
1. **100% Local Wi-Fi (RFC 1918 Only):** Приложение работает **строго внутри домашней локальной сети** (`192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`). Любые запросы к внешним IP, внешним сайтам, парсерам или телеметрии **запрещены**.
2. **Zero Shell Injection:** Вызовы `adb` выполняются только через массив аргументов `tokio::process::Command`, без конкатенации сырых строк.
3. **Защита ОС ТВ:** Никогда не удалять системный пакет `com.google.android.tungsten.setupwraith` (вызывает чёрный экран `FallbackHome`).
4. **Бережный кэш:** Настройки TorrServe на ТВ всегда должны удерживать `UseDisk: false` (кэш только в ОЗУ 64 МБ).

## 3. Специализированные умения (`.agents/skills/`) и база знаний (`docs/`)
Не держи лишние детали в памяти — при выполнении конкретной задачи активируй нужный навык:
- **`tv-pilot-scaffold`** (`.agents/skills/tv-pilot-scaffold/SKILL.md`) — архитектура Cargo Workspace, структура модулей `tv-pilot-core` и команд `tv-pilot-cli`.
- **`tv-media-control`** (`.agents/skills/tv-media-control/SKILL.md`) — протоколы ADB (`:5555`), API `TorrServe MatriX.147` (`:8090`), формула скоринга потоков под 2 ГБ ОЗУ (6–18 ГБ, отсев >28 ГБ Remux) и пробуждение из `dreamx`.
- **`tv-security-audit`** (`.agents/skills/tv-security-audit/SKILL.md`) — внешний аудит безопасности ТВ, белый список APK, проверка разрешений, VPN `wg0` и фильтрация `.apk`/`.exe` в торрентах.
- **Полный отчёт по тюнингу ТВ:** `docs/TCL_GoogleTV_Optimization_Guide.md` (все выполненные шаги деблоата и замеров «Было / Стало»).
