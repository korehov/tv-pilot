## 1. 🛠️ Включение режима разработчика и предоставление доступа ИИ-агенту

Чтобы управлять телевизором удаленно с ПК и позволить агенту выполнять команды оптимизации через **ADB (Android Debug Bridge)**:

### Шаг 1. Активация режима разработчика на ТВ
1. На пульте нажмите кнопку **Настройки** (шестерёнка) → **Система** → **Об устройстве**.
2. Опуститесь до пункта **«Сборка ОС Android TV»** (или «Номер сборки»).
3. Нажмите центральную кнопку **ОК 7 раз подряд**, пока внизу не появится уведомление:  
   *«Вы стали разработчиком!»*.

### Шаг 2. Включение отладки по сети / USB
1. Вернитесь назад: **Настройки** → **Система** → появится новый пункт **«Для разработчиков»**.
2. Внутри найдите и включите тумблер:
   * **«Отладка по USB» (USB debugging)** — *на Google TV включение этого пункта автоматически открывает порт `5555` для подключений по локальной сети Wi-Fi/Ethernet!*
3. Посмотрите IP-адрес телевизора: **Настройки** → **Сеть и интернет** → выберите вашу сеть (например, `172.30.0.176`).

### Шаг 3. Подключение ИИ-агента с ПК
1. На компьютере установите утилиту ADB (через PowerShell):
   ```powershell
   winget install Google.PlatformTools
   ```
2. Подключитесь к телевизору командой:
   ```powershell
   adb connect <IP_ТЕЛЕВИЗОРА>:5555
   ```
3. 🔴 **Внимание на экран ТВ:** при первом подключении на телевизоре всплывёт окно с запросом ключа RSA:  
   *«Разрешить отладку по USB с этого компьютера?»*.
4. Отметьте галочку **«Всегда разрешать с этого компьютера»** и нажмите пультом **«Разрешить»**.
5. Проверьте статус подключения:
   ```powershell
   adb devices
   # Должно быть: <IP_ТЕЛЕВИЗОРА>:5555    device
   ```

## 2. ⚡ Оптимизация системных настроек в меню разработчика

В меню **Настройки** → **Система** → **Для разработчиков** (или через прямые команды ADB) примените следующие параметры для ускорения:

### 🚀 Анимации интерфейса (Мгновенный визуальный отклик)
По умолчанию скорость анимаций равна `1.0x`. Уменьшение до `0.5x` ускоряет раскрытие окон и меню в два раза:
* **Анимация окон (Window animation scale):** `0.5x`
* **Анимация переходов (Transition animation scale):** `0.5x`
* **Длительность анимации (Animator duration scale):** `0.5x`

*Команды через ADB:*
```powershell
adb shell settings put global window_animation_scale 0.5
adb shell settings put global transition_animation_scale 0.5
adb shell settings put global animator_duration_scale 0.5
```

### 📉 Буфер журнала логов (Logger buffer size)
* **Значение:** Отключить (**Выкл**) или поставить минимальные **64 КБ** (по умолчанию часто стоит 256K или 1M).
* **Эффект:** Экономит оперативную память и снижает нагрузку на медленную флеш-память ТВ постоянной записью системных логов.

### 🚫 Ограничение фоновых процессов (Background process limit)
* **Значение:** **Стандартный лимит** или максимум **3–4 процесса**.
* **Совет:** Не ставьте «Без фоновых процессов», иначе при выходе из плеера в меню приложение будет намертво закрываться и сбрасывать позицию воспроизведения.

## 3. 🧹 Полный деблоат: удаление телеметрии и фонового мусора

Для устройств с 2 ГБ RAM удаление фоновых системных аппетитов производителя — главный шаг к стабильности.

### 🚨 Главный вредитель: `com.tcl.guard` («Защитник»)
Фирменный антивирус/клинер TCL:
* Держит два процесса в RAM, потребляя **~170 МБ оперативной памяти**.
* Агрессивно выгружает фоновые сервисы — именно из-за него самопроизвольно **вылетают TorrServe и WireGuard**.

### 💻 Команды для удаления всего мусора разом:

Выполните в консоли ПК через ADB (пакеты удаляются безопасно для пользователя `user 0`, без root-прав):

```powershell
# 1. Фирменный «Защитник» TCL (освобождает 170 МБ и спасает TorrServe)
adb shell pm uninstall -k --user 0 com.tcl.guard

# 2. Системные сборщики логов, телеметрия и аналитика
adb shell pm uninstall -k --user 0 com.tcl.logkit
adb shell pm uninstall -k --user 0 com.tcl.bi
adb shell pm uninstall -k --user 0 com.google.android.feedback

# 3. Маркетинговые промо, пуш-уведомления и реклама TCL
adb shell pm uninstall -k --user 0 com.tcl.messagebox
adb shell pm uninstall -k --user 0 com.tcl.overseasappshow
adb shell pm uninstall -k --user 0 com.tcl.tv.tclhome_passive
adb shell pm uninstall -k --user 0 com.tcl.dashboard
adb shell pm uninstall -k --user 0 com.tcl.waterfall.overseas
adb shell pm uninstall -k --user 0 com.tcl.channelplus
adb shell pm uninstall -k --user 0 com.tcl.partnercustomizer

# 4. Профилирование и ненужные аккаунты TCL
adb shell pm uninstall -k --user 0 com.tcl.usercenter
adb shell pm uninstall -k --user 0 com.tcl.useragreement
adb shell pm uninstall -k --user 0 com.tcl.smartalexa

# 5. Ненужные предустановленные тяжелые сервисы
adb shell pm uninstall -k --user 0 com.netflix.ninja
adb shell pm uninstall -k --user 0 com.amazon.amazonvideo.livingroom
adb shell pm uninstall -k --user 0 com.wbd.stream
adb shell pm uninstall -k --user 0 com.iqiyi.i18n.tv
adb shell pm uninstall -k --user 0 com.google.android.syncadapters.calendar
```

*(Если какое-то приложение понадобится вернуть, его можно восстановить командой: `adb shell cmd package install-existing <имя_пакета>`)*.

## 4. ⚠️ Важная системная ловушка: Черный экран (FallbackHome)

> 🛑 **КРИТИЧЕСКИ ВАЖНО:**  
> Никогда **не отключайте** пакет `com.google.android.tungsten.setupwraith` (Мастер первичной настройки Google TV) до тех пор, пока полностью не пройдёте все экраны синхронизации аккаунта Google!

### Что происходит при ошибке:
Если отключить `setupwraith` и перезагрузить ТВ, лаунчер Google TV не сможет показать экран подтверждения аккаунта и выпадет в аварийную заглушку **`FallbackHome` (полностью черный экран без реакции на пульт)**.

### Как починить, если экран стал черным:
Подключитесь по ADB и верните мастер настройки одной командой:
```powershell
adb shell cmd package install-existing com.google.android.tungsten.setupwraith
adb shell input keyevent 3
```
На экране мгновенно появится диалог Google — подтвердите аккаунт пультом, и рабочий стол загрузится штатно.

## 5. 📺 Режим «Только приложения» (Apps-only mode)

Самый сильный системный буст плавности интерфейса Google TV.

### Как включить:
**Настройки** → **Учетные записи и вход** → выберите свой Google-аккаунт → включите тумблер **«Режим: только приложения»** (Apps-only mode).

### Что дает:
* С главного экрана исчезают все тяжелые рекламные ленты, рекомендации фильмов и автовоспроизведение трейлеров.
* Лаунчер потребляет всего **~115 МБ RAM** (вместо ~250 МБ).
* Нагрузка на процессор от домашнего экрана падает с **33% до 2.7%**!

## 6. 🏪 Возврат иконки Google Play Store в режиме «Только приложения»

В режиме «Только приложения» Google скрывает иконку Play Store. Чтобы вернуть удобную плитку магазина прямо в строку ваших приложений:

1. Скачайте открытый легковесный шорткат-модуль (47 КБ) на ПК:
   ```powershell
   Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Bigmoco/apponlymode/main/GooglePlayStore_shortcut.apk" -OutFile "c:\temp\GooglePlayStore_shortcut.apk"
   ```
2. Установите его на ТВ через ADB:
   ```powershell
   adb install -r "c:\temp\GooglePlayStore_shortcut.apk"
   ```

## 7. 🎬 Оптимизация медиаплееров (SmartTube и TorrServe)

### SmartTube (YouTube без рекламы):
1. **Анимированные превью карточек:** Отключить.
2. **Формат видео (Кодек):** Приоритет **VP9** (или AVC).
3. **Размер буфера:** Средний или Маленький (15–20 сек).
4. **Разрешение интерфейса:** 1080p.

### TorrServe MatriX (Просмотр торрентов на лету):
* На устройствах с 2 ГБ RAM установите:
  * **Размер кэша в ОЗУ (RAM Cache):** **64 МБ** (`UseDisk: false`).
  * **Буфер предзагрузки:** 10–15%.

## 8. 🧠 Интеграция Google Gemini на большой экран

1. Установите специализированный браузер **TV Bro** (`com.phlox.tvwebbrowser`).
2. Выдайте системный доступ к микрофону для голосовых промптов:
   ```powershell
   adb shell pm grant com.phlox.tvwebbrowser android.permission.RECORD_AUDIO
   ```
3. Откройте в TV Bro страницу **`https://gemini.google.com`**.

## 9. 📊 Результаты оптимизации: «Было» vs «Стало»

| Параметр | До оптимизации («Из коробки») | После оптимизации | Результат |
|---|---|---|---|
| **Доступная память (`MemAvailable`)** | 427 МБ | **737 МБ** | 🟢 **+310 МБ (+72%) чистого запаса** |
| **Память в режиме проигрывания 4K** | ~80 МБ (на грани сбоя) | **~440 МБ стабильного резерва** | 🟢 Защита от вылетов плееров |
| **Простой процессора (`CPU Idle`)** | 281% idle (нагрузка ~120%) | **345% idle (нагрузка ~55%)** | 🟢 **CPU разгружен более чем в 2 раза** |
| **Нагрузка при воспроизведении видео** | Высокая, фоновые микрофризы | **~18% суммарная нагрузка CPU** | 🟢 Холодный чипсет, чистый аппаратный OMX |
| **Нагрузка домашнего экрана** | ~33% CPU, постоянный трафик | **2.7% CPU, нулевой трафик** | 🟢 Мгновенный отклик на пульт |
| **Фоновые демоны телеметрии** | 10+ скрытых служб TCL/Google | **0 активных трекеров** | 🟢 Чистая сеть и приватность |
| **Стабильность TorrServe / VPN** | Закрывались «Защитником» каждые 15 мин | **Работают непрерывно часами** | 🟢 Полная автономность фоновых служб |
